# Bat Connect Demo

Demo navegável em Flutter para o projeto Bat Connect / Bat Collect.

## O que contém
- Tela inicial com escolha de perfil
- Demo da Empresa
- Demo do Batedor com Online/Offline, aceitar/recusar e check-in
- Menu do Batedor
- Demo do Administrador
- Regras visuais da Bat Collect: PIX/boleto e split 10% / 90%

## Como abrir
1. Instale Flutter.
2. Na pasta do projeto, rode:
   flutter pub get
   flutter run

## Observação
Esta é uma DEMO navegável. Integrações reais com Firebase, GPS, Google Maps e pagamentos devem ser configuradas antes de produção.
